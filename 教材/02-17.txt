# 语法点
宾格与格代词同时出现的语序规则
当动词的直接宾语和间接宾语同时分别由宾格和与格人称代词指代时，与格代词在前，宾格代词在后。即：与格代词 + 宾格代词 + 变位动词。例如：Te lo traigo（我把它带给你，te=与格，lo=宾格）、Nos las contestáis（你们回答我们这些问题，nos=与格，las=宾格）。
对应例句：1,2,3,4,5,6

与格代词第三人称的变体se
当与格代词第三人称le或les与宾格代词lo/la/los/las同时出现时，le/les必须变为se。这是为了避免le lo/les la等音素重复。se在这里不是自复代词，而是与格代词的变体。例如：se las llevo（我把它们带给他/她/您/他们，se代替le/les）、se la entrega（把它交给他/她，se代替le）。
对应例句：4,5,6

代词置于原形动词之后连写
宾格和与格代词可以置于能愿动词或动词短语之前分写，也可以置于原形动词之后与之连写。连写时，为保持动词原形的重音不位移，需在原来的重读音节上添加重音符号。例如：Te lo voy a traer. = Voy a traértelo.（我把它带给你）。两种语序意思完全相同。
对应例句：7,8,9,10,11,12

重音符号添加规则
代词与原形动词连写时重音符号的添加：traer + te + lo → traértelo（重音保持在traer的e上），prestar + os + las → prestároslas（重音保持在prestar的a上），devolver + nos + las → devolvérnoslas（重音保持在devolver的e上）。重音符号的作用是保持原形动词原有的重音位置不因代词后附而发生位移。
对应例句：8,10,12
