# 生词
uno de estos	这些中的一个（固定搭配：uno de + 复数名词，意为"…之一"）
hablar de	谈论（动词 + 介词固定搭配：hablar 表"谈论"时必须搭配介词 de）
pequeña	小的（形容词，阴性单数，形容阴性名词，如 habitación pequeña 小房间）
pregunta a	问（某人）（动词 + 介词搭配：preguntar 表"问某人"时用介词 a 引出被问者，英文 ask someone）
cumplir con	履行、完成（动词 + 介词固定搭配：cumplir 表"履行/完成"时必须搭配介词 con；英文按语境译 follow / meet / do，口语中很少用 comply with）
todo el tiempo	(All the time)一直、始终、总是（不定代词 todo + 定冠词 el + 名词 tiempo 的固定搭配，意为"所有时间"；同义表达 a todas horas）
suben a	上楼去、上去（动词 subir 的空间义，搭配介词 a 表示方向"向上去"；复习课易混点：01-07 课中 subir 释义为"上升"（抽象义），本课复习的是空间义"上楼/上去"）
poner cosa en	把...放在...（动词 + 介词固定搭配：poner 表"放置"时用 en 引出位置，= put sth on/in）
salir de	离开、从...出去（动词 + 介词固定搭配：salir 表"离开某地"时必须搭配介词 de；注意与 salir a（出去到某地/做某事）、salir con（和…一起出去）、salir para（出发去）的区分）

# 语法点
不定代词 uno + de + 复数名词
uno 是阳性单数不定代词，可与介词 de 和一个复数名词构成"…之一"的表达：uno de estos/estos libros（这些书之一）、uno de esos/esas cosas（那些东西之一）、uno de los que...（…的那些人之一）。本课复习课例句 Yo vengo a uno de estos.（我来参加其中一个。）即此结构。注意：uno 在此结构后**谓语动词用单数第三人称**：Uno de estos libros es mío.（这些书里有一本是我的。）也可单独省略名词使用，如 uno de estos = 这些里面的一个。
对应例句：9

动词 hablar 与介词 de 的搭配
hablar 意为"说话、交谈"，表示"谈论某事"时必须搭配介词 de，构成 hablar de + 名词/动词原形/从句 的结构，不可省略或替换介词（书面语中 sobre 可替换 de，但口语习惯用 de）。本课复习课两处例句 Paco y José hablan de su familia.（帕科和何塞聊起了家人。）和 José y Paco hablan de acostarse.（何塞和帕科聊起了睡觉。）均使用此搭配，其中后一句 de 后接动词原形 acostarse，相当于英语的 talk about doing sth。
对应例句：7,54

目的状语 para + 动词原形
介词 para 后接动词原形，构成目的状语，意为"为了（做某事）"，用于说明主句动作的目的或意图。para 本身已含"为了"之意，结构紧凑，对应英文 in order to / to。复习课例句 Para poder cumplir, estudio mucho.（为了能完成，我学习很多。）中 para 后接情态动词原形 poder + 实义动词原形 cumplir 的复合结构；同类用法有 para hablar bien（为了说好）、para poder entender（为了能听懂）。注意与 a + 动词原形（时间，"一…就…"）和 de + 动词原形（补语/表语）的区别。
对应例句：38

动词 subir 的多义辨析
subir 是 01-07 课已学动词，基础义为"上升"，但在不同搭配中含义差别较大，复习课常见用法有四类：1) subir (a) + 地点 → 上去、上楼（空间义，介词 a 表方向；复习课例句 José y Paco suben al dormitorio. 何塞和帕科上楼去宿舍。）；2) subir + 价格/温度/数量 → 上涨、上升（抽象义，无介词；例 subir el precio 涨价）；3) subir (a) + 交通工具 → 登上、上车（介词 a 表方向；例 subir al autobús 上公交车）；4) subir + 直接宾语 → 举起、抬起或上传（例 subir las manos 举手、subir una foto a internet 上传照片到网络）。注意 1 和 3 虽都用介词 a，但 1 的宾语是目的地，3 的宾语是交通工具，需根据语境区分。
对应例句：44

动词 cumplir 带 con / 不带 con 的区别
cumplir 在不同含义下对介词 con 的要求不同，核心区分如下：
1) cumplir con + 义务/任务/承诺/功课 → 履行、完成（某项责任），con 引出被履行的对象，不可省略：Cumplo con todas mis asignaturas.（我完成所有科目。）、Sí, cumplo con todo.（是的，我完成一切。）
2) cumplir + 时间/岁数 → 满、达到（某个时间或岁数），此为及物用法，不加 con：cumplir años（过生日，见 01-16-B 课）、cumplir 18 años（满 18 岁）。
3) 当 cumplir 后无直接宾语（如用于情态动词后或目的状语中），con 也随之省略：Para poder cumplir, estudio mucho.（为了能完成，我学习很多。）
记忆口诀：责任义务用 con，岁数时间不用 con；无宾语时 con 自然消失。
对应例句：35,36,37,38
