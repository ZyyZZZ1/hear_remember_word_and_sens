# 收藏生词 Skill

## 何时使用

用户想把一个西班牙语词或短语加到收藏夹（favorites.json），以便程序能识别和复习它。

## 两种情况

### 情况一：该词已是某课生词区的独立条目

**判断标准：** 在 `教材/` 目录下某课的 `# 生词` 区段中，能找到**完全一致**的条目（左列西语与要加的词完全相同）。

**操作：** 只需在 `favorites.json` 中把该词加到对应课课号的数组里。

示例：用户要收藏 `verano`，在 `教材/01-16.txt` 的生词区找到了 `verano	夏天`，则只需在 `favorites.json` 的 `"01-16"` 数组中加入 `"verano"`。

### 情况二：该词不是任何课的独立生词条目

**判断标准：** 在所有 `教材/*.txt` 的 `# 生词` 区段中，找不到完全一致的左列条目。常见于以下子情况：

1. **短语/固定搭配**：如 `cursos de verano`、`todos los años`、`por la mañana` 等，虽然组成部分在生词区，但整个短语不是独立条目。
2. **动词变位形式**：如 `puedes`、`hablan` 等，生词区只有原形 `poder`、`hablar`，没有变位形式作为独立条目。
3. **教材例句或语法点中出现的词**：没有出现在任何课的生词区。

**操作：** 需要做**两件事**：

1. **在对应课的生词区添加该词为独立条目**：
   - 确定该词/短语最相关的那一课（通常是最先出现该词的课，或用户指定的课）
   - 在该课 `教材/XX-XX.txt` 的 `# 生词` 区段末尾添加一行：`西语词	T中文释义`
   - 这一步确保程序能从生词表识别到它

2. **在 `favorites.json` 中把该词加到对应课号数组里**：
   - 这一步确保收藏夹能显示它

示例：用户要收藏 `todos los años`，它在 01-16 例句中出现但不是独立生词。
- 先在 `教材/01-16.txt` 的生词区末尾加一行：`todos los años	每年`
- 再在 `favorites.json` 的 `"01-16"` 数组中加入 `"todos los años"`

## 执行步骤

1. **读取 `favorites.json`** 了解当前收藏状态
2. **读取相关课的教材文件** 确认生词区是否有完全一致的条目
3. **判断属于情况一还是情况二**
4. **情况一**：只在 `favorites.json` 对应课号数组中加入该词（去重）
5. **情况二**：
   a. 在对应课的 `教材/XX-XX.txt` 生词区末尾加一行 `词\t释义`
   b. 在 `favorites.json` 对应课号数组中加入该词（去重）
6. **确认修改**：向用户报告完成了什么操作

## 注意事项

- favorites.json 中同一个课号下的词不要重复添加
- 生词区的格式必须与现有条目一致：西语和中文之间用 Tab 分隔
- 如果用户要收藏的词跨越多课（如短语中的词分属不同课），以短语**整体首次出现**的课为准
- 动词变位形式如果需要作为独立生词条目添加，中文释义格式参考教材中已有的变位条目格式（如 `hablo	我说`）

### 情况三：收藏词在 `favorites.json` 中的课号与生词区所在课不一致（**收藏放错位置**）

**判断标准：** 用户（或 AI）把一个词加入了 `favorites.json` 的某课号数组下，但该课的 `# 生词` 区段里**没有**这个词的独立条目，而这个词在**另一课**的生词区里有。

**症状：** 程序无法显示该收藏词：
- 单课收藏组（`main.py:1175`）：`fav_items = [it for it in all_items if it["es"] in fav_words]`，`all_items` 取自当前课 `TEXTBOOK["vocab"]`，匹配不上就跳过。
- 收藏集（`main.py:284-298`）：`_build_favorites_textbook()` 按 `fav.get(tb["name"], [])` 遍历每课，但只在该课 `tb["vocab"]` 中匹配，匹配不上就不收。

**操作：** 只需**移动** `favorites.json` 中该词到正确的课号数组下，**不动教材生词区**（因为该词在正确课的生词区里已经存在）。

**判断正确课号的方法：**
1. 用 `grep` 在 `教材/*.txt` 的 `# 生词` 区段内搜索该词（或其最接近的原形/独立条目）作为左列
2. 找到的第一个匹配所在课即为正确课号
3. **注意课号是文件名去掉 .txt**（见 `main.py:158` `os.path.splitext(basename)[0]`）：
   - `教材/01-16.txt` → key = `"01-16"`
   - `教材/01-16-A.txt` → key = `"01-16-A"`（复习课是独立 key，不是 `01-16`）
   - 同理 `01-15.txt` 和 `01-15-B.txt`（如有）也是两个独立 key

**示例：** 用户把 `te levantas` 加到了 `favorites.json` 的 `01-16`，但 `教材/01-16-A.txt` 的生词区没有 `te levantas`；用 grep 搜到 `教材/01-11.txt:24` 有 `te levantas	你起床`。应把 `te levantas` 从 `01-16` 数组**移到** `01-11` 数组。

**为什么不能"复制"一份到 01-16 生词区？** 因为生词区重复定义同一变位形式会造成学习冗余（`te levantas` 在 01-11 已学过），且 `main.py:1175` 的过滤只看当前课 vocab，复制到 01-16 反而污染数据。**移动而不是复制**是正确做法。
