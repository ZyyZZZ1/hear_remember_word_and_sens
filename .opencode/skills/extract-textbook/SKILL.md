# 提取教材 Skill

本 Skill 的详细规则已写在 `教材提取规范.md` 中。执行时严格按照该文件的第四~九章执行。

## 快速参考

- 输入：`原生教材/` 下的 `.txt` 文件
- 输出：`教材/` 下同名 `.txt` 文件，UTF-8 编码，Tab 分隔
- 三段式结构：`# 生词` → `# 例句` → `# 语法点`
- 生词提取规则：只列入在前面所有课中未出现过的词/短语
- 例句：按原文出现顺序，每行一句，去重
- 语法点：标题 + 正文 + 对应例句编号
- 如果 `教材/` 下已存在同名文件，跳过不覆盖

## 执行步骤

1. 列出 `原生教材/` 和 `教材/` 的内容
2. 确定需要生成的课（原生有但教材没有的）
3. 按编号从小到大逐课处理
4. 每课：读取原生 → 汇总前面所有课的生词 → 提取 → 写入教材 → 自查
5. 自查清单见 `教材提取规范.md` 第八章
