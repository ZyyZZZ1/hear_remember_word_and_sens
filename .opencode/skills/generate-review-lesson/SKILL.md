# 生成复习课 Skill

## 何时使用

用户想在某课之后创建一个复习课（如 `01-16-A`、`01-20-B` 等）。

## 文件格式

文件放在 `教材/` 目录下，文件名格式：`XX-XX-<大写字母>.txt`（如 `01-16-A.txt`）。`XX-XX` 表示复习课插入位置（在前一课之后、该编号课之前），大写字母表示同位置的第几个复习课（`A`=第 1，`B`=第 2，`C`=第 3……）。

内容格式与普通教材一致，但**只有例句区，没有生词区和语法点区**：

```
# 例句

西语句子1	中文翻译1
西语句子2	中文翻译2
...
```

## 核心约束

### 1. 必须覆盖所有收藏生词

读取 `favorites.json`，把其中所有词/短语都用在文章中。逐一核对，不得遗漏。

### 2. 非生词只能用已学教材范围内的词汇

确定复习课的"已学范围"：从 `01-03` 到复习课前最后一课（如复习课叫 `01-16-A`，则范围是 `01-03` 到 `01-15`，因为 `01-16-A` 插在 `01-15` 之后）。

文章中除了收藏生词之外的所有词汇，必须在已学范围内出现过（包括生词区、例句区、语法点区）。**不得使用任何超纲词。**

### 3. 每行只放一句话

每行西语只有**一个完整句子**。不要把两句话塞进同一行。例如：

❌ 错误：
```
¡Hola, José! ¿Puedes venir a mi residencia esta tarde?	你好，何塞！你今天下午能来我的宿舍吗？
```

✅ 正确：
```
¡Hola, José!	你好，何塞！
¿Puedes venir a mi residencia esta tarde?	你今天下午能来我的宿舍吗？
```

### 4. 文章风格

- 日常化、口语化的故事或对话
- 场景转换时加旁白句（如 `Paco y José se sientan en la sala de estar.`）
- 旁白也必须占独立一行，西语\t中文格式
- 话题转换自然，用旁白或过渡句衔接，不要突兀跳转

### 5. 收藏生词中如有 01-17+ 才学的词也可使用

`favorites.json` 中可能包含进度超前课的词（如 `salir`、`acostarse` 等来自 01-17），这些词允许出现在文章中。

## 执行步骤

1. 读取 `favorites.json` 获取所有收藏生词及其课号
2. 确定复习课的已学范围（`01-03` 到前一课）
3. 读取已学范围内的所有教材文件，构建已学词汇集合
4. 起草文章，确保：
   - 所有收藏生词被自然地用在文章中
   - 旁白和过渡句让场景和话题转换流畅
   - 每行只有一句话
   - 非收藏词都在已学范围内
5. 词汇验证：逐一检查文章中每个西语词，确认要么是收藏生词，要么在已学范围内出现
6. 如发现超纲词，用已学范围内表述替换
7. 收藏生词中如有不在任何课生词区的独立条目（如短语 `todos los años`），需同时：
   a. 在对应课生词区加一行
   b. 在 favorites.json 确认已有该条目
8. 写入文件到 `教材/` 目录

## 验证清单

完成生成后，逐条检查：

- [ ] 所有 favorites.json 中的收藏词都出现在文章中
- [ ] 文章中非收藏词全部在已学范围内
- [ ] 每行只有一句话（以 `.` `?` `!` 为句末标记）
- [ ] 旁白/过渡句自然，话题不突兀
- [ ] 需要独立生词条目的收藏词已添加到对应课的生词区
- [ ] 文件名格式正确
